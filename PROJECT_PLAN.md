# BloodBridge-AI

## Team
Omni_BioTech_15
Members: G. Akshaya & K.srinidhi

## Problem
Blood banks face shortages and wastage due to no real-time coordination.

## Solution
Real-time platform to match hospital blood demand with blood bank supply using AI.

## Tech Stack
Frontend: React.js
Backend: Python, Flask
Database: Firebase
APIs: Google Maps, SMS

## Features
1. Real-Time Inventory
2. AI Matching Engine
3. Expiry Alerts
4. Location Search
